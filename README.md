# JobATS - MERN Application Tracking System

## Overview
JobATS is a full-stack Applicant Tracking System developed using the MERN stack. The platform enables recruiters to post jobs, manage applications, schedule interviews, and track candidates efficiently.

## Features
- Role-based Authentication
- Job Posting and Management
- Resume Upload and Application Tracking
- Interview Scheduling
- Analytics Dashboard
- Secure JWT Authentication

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
